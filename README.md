# Experiment 6: Role-Based and Negative Prompting

## Aim
To demonstrate how role-based prompting and negative prompting influence the tone, vocabulary, and constraint adherence of Large Language Model (LLM) responses.

## Problem Statement
Generate responses to "Explain the importance of exercise" using three conditions:
1. Baseline prompting
2. Role-based prompting
3. Role-based prompting with negative constraints

## Algorithm
1. Define the common question.
2. Create three prompt versions.
3. Initialize the Gemini API.
4. Use the same model and temperature for all prompts.
5. Collect and display the three responses.
6. Compare tone, vocabulary, and adherence to constraints.
7. Summarize the observations.

## Technologies Used
- Python
- Google Colab
- Google Gemini API
- Pandas

## Evaluation Criteria
- **Tone:** Does the response sound motivational and coach-like?
- **Vocabulary:** Does the response use simple or technical words?
- **Constraint adherence:** Does the final response avoid medical jargon and weight-loss references?

## Execution
1. Add `GEMINI_API_KEY` to Google Colab Secrets.
2. Run the notebook.
3. Review the three model responses and the constraint checks.
4. Save a screenshot in the `outputs` folder.

## Conclusion
The experiment compares the influence of role assignment and negative instructions on LLM responses. Results must be evaluated from the actual outputs generated by the model. Keyword-based checks provide an initial indication of constraint adherence, but manual review is also necessary.
